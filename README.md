# 🎮 Rock Paper Scissors

A gesture-controlled Rock Paper Scissors game built using Python, OpenCV and MediaPipe.

## 📌 About

This project uses a webcam to detect hand gestures and allows the user to play Rock Paper Scissors using hand movements.

The system recognizes three gestures:

- ✊ Rock
- ✋ Paper
- ✌️ Scissors

## 🛠️ Technologies Used

- Python
- OpenCV
- MediaPipe

## ✨ Features

- Real-time webcam input
- Hand gesture detection
- Rock gesture recognition
- Paper gesture recognition
- Scissors gesture recognition
- Real-time computer vision
